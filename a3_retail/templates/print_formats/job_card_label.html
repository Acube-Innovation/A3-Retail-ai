{#- The sticker that goes on the device itself. Read by a scanner, not by a person: the barcode carries the job card number, which is what the technician's screen and the delivery counter both search by. The two lines of text are for the human holding the tray — whose phone is this, and which phone is it. The barcode carries `26-00053` rather than the whole `JC-SVP-26-00053`. See `a3_scan_code` — the `JC` and the branch are the same on every sticker a branch prints, so they cost bars and say nothing, and the search finds the card either way, because every screen searches document numbers by what they contain and `JC-SVP-26-00053` contains `26-00053`. That is also why the hyphen stays: `2600053` would be a third fewer bars and would fit a module half again as wide, but nothing would find it. THE ROLL IS TWO ACROSS, and that is why this page is as wide as the print head rather than one sticker. Sent a page narrower than the paper, the printer centres it on the web and the label comes out straddling the gap between the two stickers — half on each. Nothing on the printer fixes that: it decides where a narrow page goes. So the page is the full head and each sticker is placed on it here, which puts the position under this template's control and makes it something a test print can measure. Both stickers carry the same job card. A feed advances the whole row whether one is used or two, so the second is spent either way — one goes on the phone, the other on the job bag it travels in. -#} {#- ---------------------------------------------------------------------- The roll, measured with a ruler against a test print. If the stock ever changes these five numbers are the only thing to touch. The page is declared in points, not millimetres or inches, because that is the one unit Chrome will not round: asked for 4.09in it returned 294pt, which is 4.0833in, and the template's arithmetic was then a tenth of a millimetre out from the page it was actually drawn on. 288pt is exactly four inches, and that number is not arbitrary. A driver rasterises a page at `inches x 203`, so only a whole number of inches comes out as a whole number of dots — 812 of them — which makes the scale exactly 203/25.4 dots to the millimetre, the same figure the barcode is laid out in. At any other width the two disagree by about a tenth of a percent, and that was enough to lose a dot out of the middle of the stop pattern on one of the two stickers. Which edge it lands on depends on the number being encoded, so it could not have been tuned out. `cell_dots` is the width actually drawn on each sticker — 368 dots, about 46mm, against the sticker's 50. Two stickers and the gap come to 104.25mm and the page is 101.6, so the cells cannot be the full width; what is lost is blank label at the outer ends either way. It is an even number of dots so that the margin centring the symbol inside it is a whole number too. The two cells are placed symmetrically about the middle of the page rather than measured in from its left edge, because the printer centres what it is given: centred placement lands correctly wherever it decides the middle is, while measuring from the left only works if that guess is right. `shift_mm` is the one knob for correcting it — positive moves both stickers to the right. ------------------------------------------------------------------- -#} {%- set page_pt = 288 -%} {#- exactly 4in = 101.6mm; see below -#} {%- set tall_pt = 66 -%} {#- 23.3mm, the sticker's height -#} {%- set sticker_mm = 50.0 -%} {#- one sticker, ruler-measured -#} {%- set gap_mm = 4.25 -%} {#- between the two stickers -#} {%- set shift_mm = 0.0 -%} {#- nudge both right (+) or left (-) -#} {#- Everything below is worked out in printer dots and only turned back into millimetres to be written into the page, because a bar edge that lands on half a dot rounds whichever way the renderer feels like. The roll's pitch is 54.25mm, which is 433.6 dots — not a whole number — so two cells placed exactly that far apart cannot both sit on the dot grid, and the one that lands worst grows an element a single dot wide. Snapping the pitch to 434 dots moves a sticker by five hundredths of a millimetre, which is nothing on a 50mm label, and puts both symbols on the grid. -#} {%- set dpm = 203 / 25.4 -%} {%- set page_mm = page_pt * 25.4 / 72 -%} {%- set scan = a3_scan_code(doc.name) -%} {%- set bar_mm = a3_label_barcode_mm(scan, sticker_mm - 4) -%} {%- set bar_dots = (bar_mm * dpm) | round | int -%} {#- The cell is an even number of dots wider than the symbol, so the margin that centres the symbol in it is a whole number of dots too. 384 dots is 48.05mm: a little under the 50mm sticker, because two stickers and the gap come to 104.25mm and the head is only 104mm. -#} {%- set cell_dots = 368 -%} {%- set cell_mm = cell_dots / dpm -%} {%- set pad_mm = ((cell_dots - bar_dots) / 2) / dpm -%} {%- set pitch_dots = (( sticker_mm + gap_mm) * dpm) | round | int -%} {%- set pitch_mm = pitch_dots / dpm -%} {%- set first_dots = ((page_mm / 2 + shift_mm - pitch_mm / 2 - cell_mm / 2) * dpm) | round | int -%} {%- set first_mm = first_dots / dpm -%} {%- set second_mm = (first_dots + pitch_dots) / dpm -%} {#- One sticker's worth, so the two cannot drift apart. -#} {%- macro sticker(doc, left_mm) -%}
