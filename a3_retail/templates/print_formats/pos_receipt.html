{#- The page is exactly as long as the slip, measured rather than guessed. A thermal page has to name a height — `size: 80mm auto` is not valid CSS — and no formula gets it right, because what makes one receipt longer than another is how many lines the branch's own terms run to and how often an item name wraps. Estimating it either cut the total onto a second slip or fed a hand of blank roll after every sale. So the slip measures itself the moment it is drawn and writes its own page height. This runs before Frappe's own `window.print()`, which is appended after it. If scripts are blocked the Jinja estimate above still stands, so the worst case is the old behaviour rather than no receipt. -#}
